# Tree CLI Utility

`tree` — это простая и быстрая консольная утилита для визуализации структуры каталогов в виде графического дерева прямо в вашем терминале. Помогает быстро понять устройство проекта или задокументировать структуру папок.

## Возможности

- **Рекурсивный вывод:** отображение полной структуры папок и файлов.
- **Ограничение глубины (`-L`):** просмотр структуры только до нужного уровня вложенности.
- **Фильтрация:** вывод только директорий (`-d`) или отображение скрытых файлов (`-a`).
- **Сортировка (`-S`, `-r`):** сортировка файлов по размеру или алфавиту, включая реверсивный режим.
- **Подсветка текста:** автоматическое цветовое выделение папок и системных ошибок.
- **Кроссплатформенность:** работает на Linux и Windows.

## Установка

### Готовые бинарные файлы
Вы можете скачать уже собранные файлы для вашей операционной системы со страницы **[Releases](../../releases)**. Просто скачайте архив, распакуйте его и добавьте исполняемый файл в вашу переменную окружения `PATH`.

### Сборка из исходников
Если у вас установлен Go (версии 1.22 или выше):

```bash
# Установка напрямую через go install
go install github.com/sundepo/tree

# Или ручная сборка
git clone https://github.com/sundepo/tree.git
cd tree
go build .
```

## Использование

```text
Usage: tree [<dir> ...] [flags]

Arguments:
  [<dir> ...]    Directory list.
```
Если директория не указана, утилита сканирует текущую папку (`.`).

### Доступные флаги:

```text
Flags:
  -h, --help         Show context-sensitive help.
  -a, --all          All files are listed.
  -d, --dir-only     List directories only.
  -L, --level=0      Descend only level directories deep.
  -r, --reverse      Reverse the order of the sort.
  -S, --size-sort    Sort files by size.
```

### Примеры команд:

```bash
# Обычный вывод текущей папки
tree

# Показать только папки на глубину не более 2 уровней
tree /path/to/project -d -L 2

# Показать абсолютно все файлы (включая .git, .env) и отсортировать их по размеру
tree . -a -S
```
