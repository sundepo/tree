# Tree CLI Utility on Go

Консольное приложение на языке Go, представляющее собой аналог классической утилиты `tree`. Программа рекурсивно обходит директории и визуализирует их структуру в виде графического дерева в терминале.

Проект разработан с упором на чистую архитектуру, масштабируемость и принципы SOLID (в частности, OCP и ISP) благодаря использованию интерфейсов для фильтрации, сортировки и вывода данных.

## Возможности

- **Рекурсивный обход (DFS):** построение полного дерева каталогов.
- **Ограничение глубины (`-L`):** управление уровнем вложенности при отображении.
- **Гибкая фильтрация:** поддержка вывода только директорий (`-d`) или отображения скрытых файлов (`-a`).
- **Кастомная сортировка (`-S`, `-r`):** сортировка элементов по алфавиту или размеру файла, а также инвертирование порядка вывода.
- **Цветовое оформление:** визуальное выделение папок и ошибок чтения прямо в консоли.
- **Кроссплатформенность:** протестировано и работает в системах Linux и Windows.

## Архитектура проекта

Код разделен на изолированные модули, взаимодействующие через интерфейсы:

- **`EntryFilter` (`filter.go`):** интерфейс для фильтрации элементов дерева. Реализован в виде паттерна «Цепочка обязанностей» (`ChainFilter`), объединяющего `DirOnlyFilter` и `HiddenFilter`.
- **`EntrySorter` (`sort.go`):** интерфейс для изменения порядка вывода. Использует паттерн «Стратегия» (`AlphabeticalSorter`, `SizeSorter`) и паттерн «Декоратор» (`ReverseSorter`) для разворота слайсов.
- **`TreeRunner` (`runner.go`, `walk.go`):** центральный компонент, управляющий обходом (DFS) и форматированием вывода. Принимает абстрактный `io.Writer`, что позволяет легко перенаправлять дерево в файлы, сетевые сокеты или буферы при тестировании.

## Установка

Для сборки приложения вам понадобится установленный [Go](https://go.dev) версии 1.22 или выше.

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd tree-cli-go
   ```

2. Скачайте зависимости:
   ```bash
   go mod download
   ```

3. Скомпилируйте исполняемый файл:
   ```bash
   go build -o tree .
   ```

## Использование

```bash
./tree [ДИРЕКТОРИИ...] [ФЛАГИ]
```

### Доступные флаги:
- `-a` — Показывать все файлы (включая скрытые, начинающиеся с точки).
- `-d` — Выводить только директории, игнорируя файлы.
- `-L <int>` — Максимальная глубина погружения в подкаталоги (по умолчанию `0` — бесконечно).
- `-S` — Сортировать элементы по размеру (от большего к меньшему).
- `-r` — Развернуть порядок сортировки на противоположный.

### Примеры:
```bash
# Вывести структуру текущей папки, включая скрытые файлы, с сортировкой по размеру
./tree . -a -S

# Отобразить только папки на глубину не более 2 уровней
./tree /path/to/project -d -L 2
```

## Тестирование и CI/CD

Проект покрыт изолированными модульными и интеграционными тестами без побочных эффектов для вашей файловой системы (используются моки для `os.DirEntry`/`fs.FileInfo` и хелпер `t.TempDir()`).

Запуск тестов локально:
```bash
go test -v ./...
```

В репозиторий интегрирован **GitHub Actions Workflow**, который автоматически запускает и проверяет тесты при каждом пуше или пулл-реквесте в операционных системах **Ubuntu** и **Windows**.
